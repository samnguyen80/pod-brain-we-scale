# Email flows

Read `${CLAUDE_PLUGIN_ROOT}/knowledge/concepts/email-flows.md` and `sources/5-1-email-marketing.md`.

Email revenue carries no acquisition cost, so it lands almost entirely on margin. Target **25-30% of revenue** from email, split roughly 50/50 flows vs campaigns.

## Popup first

8-second delay, two-step (email then confirm), 10-15% offer, excluded from /cart and /checkout so it never interrupts someone already buying. Signup rate target 5-10%.

## Six core flows

| Flow | Trigger |
|---|---|
| Welcome (6 emails) | popup signup |
| Abandoned checkout | checkout started |
| Abandoned cart | add to cart |
| Browse abandonment | viewed product |
| Site abandonment | active on site |
| Sunset | unengaged-120 segment, 5-day delay |

Post-purchase, birthday, VIP and winback are the **advanced** tier — held until $10,000 in sales, because before that the list is too thin to fire meaningfully.

Flows before campaigns: the reference account shows flows at $87K vs campaigns $45K (claimed). Flows run once and keep paying.

## Campaigns

Start once the list hits **20 subscribers**. One per week, alternating one content and one sales email — a list that only ever gets discounts stops opening anything else. Work up to 2-3/week. Default to the Engaged-90 segment; full list only for BFCM.

Klaviyo is free to 250 profiles, then roughly $50-100/month.

## Say this if they are pre-traffic

The flagship brand did ~$400K in sales before setting up email at all (claimed). The course tells that as a win; it is really repeat revenue left uncollected. The popup can go up the day the store opens.
