# Design test — gate 2

Read `${CLAUDE_PLUGIN_ROOT}/knowledge/sources/4-6-launch-design-test.md` and `concepts/testing-ladder.md`.

Same machinery as gate 1, opposite variable: one proven photo, ~100 designs.

## Build

- Budget $12.50/day, launch Thursday, review Monday.
- Catalog roughly 100 products behind the winning mockup style.
- Do not raise to $50/day until after the first full weekend review.

## Judge

Winner: under **$1.00** cost per link click on **3-5 link clicks**. The bar loosens from gate 1's "solid 5" because the same budget now spreads across ~100 designs instead of 5 photos — a deliberate trade of confidence for coverage.

Target for the first run: **2-3 winning designs out of ~100**. This gate is explicitly not about profit.

## Iterate

Swap the **concept**, not the font or colour — a recoloured loser is the same test run twice. Next batch is a 50/50 split: iterations on proven winners, and fresh research.

Then hand off to `scale-catalog`.
