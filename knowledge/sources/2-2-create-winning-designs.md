# 2.2 Create Winning Designs

Stage: 2) Design
Video: https://www.youtube.com/watch?v=hduC-C8pBpE&t=4386s
Transcript: [../../transcripts/2-2-create-winning-designs.md](../../transcripts/2-2-create-winning-designs.md)

## The job of this lesson
A merchant should walk away able to turn research into production-ready t-shirt design files using AI image generation (no design skill or prompt-engineering expertise required) plus Canva, finishing with 5 complete, upscaled, background-removed, correctly named designs ready to upload to a product.

## Playbook
1. Use the WeScale Design GPT — built specifically for POD — instead of a generic AI image tool; it already understands POD design principles, generates on a "design equation" (print/press style + art style + mood), and outputs production-ready files. `[01:13:43]`
2. Prompt it simply: "create design prompts for the [niche] niche" — it returns several ready-made prompts to test. `[01:14:14]`
3. Paste a generated prompt back into the same chat and ask it to create the image; work through the returned prompts to generate multiple designs quickly. `[01:14:49]`
4. When output isn't right, give precise corrective instructions rather than vague feedback — describe exact placement ("move the [text] to underneath the [subject] in one horizontal line") — and expect to iterate 2-3 times; common failure modes are misplaced text, dropped letters, and off-center elements. `[01:15:23]`
5. Favor designs with a plain, cleanly removable background, a low color count, and research-backed cross-niche combos (e.g. niche + alcohol, niche + patriotism, niche + a specific demographic like retirees). `[01:16:46]`
6. Generate a first batch of 5 designs, download every image, then organize: one folder per design inside the brand's master folder, both folder and file renamed to a consistent "[design name] t-shirt" convention — essential once there are hundreds of designs. `[01:20:27]`
7. Apply 5 design principles: simple is better, readable from 10 feet away, one clear message, text-heavy designs test better, simple/muted colors (max 1-3). Spend only 5-10 minutes per design. `[01:23:08]`
8. In Canva, start a custom 5000x5000px design (correct print DPI), upload all raw designs into their own canvas so each fills the frame, then run Canva Pro's background remover. `[01:24:19]`
9. Manually fix removal errors: zoom in and use "restore" to paint color back into any part of the subject (shirt, faces, limbs, small objects) erased by mistake, and erase leftover unwanted fragments. Check every image before moving on. `[01:26:05]`
10. Name each finished file 1-2 words max; if stuck, drop the design into the Design GPT for 2-3 word name suggestions. `[01:31:20]`
11. Export via Share → Download with "Transparent background" checked (zip); move each upscaled file into its correctly named folder, filing the old pre-upscale version into an "old" subfolder or replacing it. `[01:31:49]`

## Numbers and thresholds
- 5 sample designs generated live, each in 5-10 minutes `[01:23:08]`
- Outsourcing these 5 designs would otherwise cost "$100 or more" and take days `[01:33:53]` (claimed)
- Most beginners launch with only 10 designs `[01:34:24]` (claimed)
- Survey of 10,000+ WeScale sellers: over 52% run 250-500 live designs on their store, and all of those (250+ designs) had crossed $10K in sales `[01:34:24]` (claimed)
- Manually creating 100 designs used to take 3-4 weeks; with AI tools it's now "an afternoon," worth "thousands of dollars" done in one sitting `[01:34:53]` (claimed)
- Canvas export size: 5000x5000px, for correct print DPI `[01:24:19]`
- Colors per design: max 1-3 `[01:23:08]`

## Tools and services named
- WeScale Design GPT — generates POD design prompts and images `[01:13:43]`
- Canva (Pro required for background removal) — upscaling to 5000x5000, background removal, cleanup, renaming/export `[01:24:19]`

## Watch-outs
- Never use copyrighted images or logos, or copy another brand's design. `[01:23:43]`
- Don't overload a design with too many colors. `[01:23:43]`
- Don't design for personal taste — base every design on research, not random ideas, and don't skip research entirely. `[01:23:43]`
- AI image generation needs precise, specific prompting to fix errors (position, dropped letters) — vague feedback doesn't work. `[01:16:20]`
- Check every background-removed image closely: fingers, thin edges, and small text characters are commonly clipped by mistake and need manual restoration. `[01:27:12]`
- Don't second-guess or treat each design as precious ("is this good enough?") — the market decides, not personal judgment. `[01:22:21]`
