# 3.2 Brand Your Store

Stage: 3) Store
Video: https://www.youtube.com/watch?v=hduC-C8pBpE&t=11975s
Transcript: [../../transcripts/3-2-brand-your-store.md](../../transcripts/3-2-brand-your-store.md)

## The job of this lesson
A merchant should walk away able to turn the generic "Build My Pod" theme template into a niche-specific brand experience — logo, favicon, homepage banner, product page copy, trust badges, collection page, and CTA color — using AI tools (Gemini/Nano Banana for images, Claude for on-brand copy) instead of hiring a $5,000 agency.

## Playbook
1. Go to Online Store → theme editor. Replace the placeholder logo (Shopify → Images → upload your saved logo file) and keep the header thin/small so mobile visitors see more product above the fold. `[03:29:42]`
2. Crop the logo to fit tightly (use the built-in cropper, free-form, then click Apply — not just Save — before it takes effect). `[03:31:07]`
3. Upload a favicon the same way (use the Canva favicon template made earlier). `[03:32:26]`
4. Generate a homepage desktop banner: prompt Gemini/Nano Banana with your niche + "Shopify banner for homepage, desktop, emphasize the t-shirts," download, then place it into the pre-sized Build My Pod banner template block. `[03:33:26]`
5. Generate and upload a separate mobile-sized banner image — desktop images often look wrong cropped on mobile, so the theme has distinct desktop/mobile image slots. `[03:39:32]`
6. For each homepage/product-page text block, click the text directly in Build My Pod's editor (it jumps straight to the editable field, unlike stock Dawn/Horizon themes) and rewrite via Claude: paste the existing copy into your Claude Project (already primed with brand voice), specify tone (e.g., "casual and funny, passionate, laid-back," "shorter and punchy"), and paste the result back in. `[03:41:56]`
7. Replace any placeholder marketing claims from the template (e.g., "10,000 happy customers," "5 out of 5 stars") with claims you can actually stand behind (e.g., "Golfer approved," "30-day money back guarantee"). `[03:48:20]`
8. On the product page, trim size range to Small–3XL (not 4XL/5XL) so the size selector fits on one line above the fold — keeping the Add to Cart button close to the top on mobile. `[03:46:49]`
9. Edit the sizing-guide graphic using the provided editable template (spreadsheet-style), adding/removing size rows and rewording explanations (print-on-demand sizing is measured flat, not "around" like a tailor) to reduce sizing-related support tickets. `[03:49:46]`
10. Build custom trust-badge icons (e.g., "Satisfaction Guaranteed," "Free Returns," "Free Shipping," "Fast Shipping") by prompting Gemini for simple line-art icons in your niche, downloading, cropping each to the same size, and swapping them into the theme's icon blocks. Proofread AI-generated text on the icons (e.g., check "guarantee" isn't misspelled). `[03:52:41]`
11. Replace the generic lifestyle image on the product page with a niche-specific AI-generated image (prompt Gemini fresh in a new chat if it keeps recycling old context/props from prior prompts). `[03:57:44]`
12. On the collection page, replace generic claims ("10,000 happy customers") with something honest ("30-day money back guarantee"), and check the collection page title pulls in correctly. `[03:59:32]`
13. Update the announcement bar with a niche emoji + the free-shipping threshold message (e.g., "⛳ Free shipping $75+"). `[04:00:10]`
14. Write a one-line brand slogan/mission statement (the instructor used Claude/brainstorm output, e.g., "Swing bad, laugh good") and drop it into the mission-statement block. `[04:00:54]`
15. Set your CTA/button color consistently across the whole theme — pick one color and use it everywhere a customer should click (header, Add to Cart, cart button) so customers learn to recognize "the button to push." `[04:01:42]`

## Numbers and thresholds
- Bad theme baseline conversion example: 0.58% (worse than the already-bad 1.5% benchmark) `[03:20:14]`
- Ad spend behind these "keep it simple" lessons: $1.26 million tested by the instructor `[03:23:50]` (claimed)
- Best-performing CTA button colors, per the instructor's testing: red, green, black `[04:01:42]` (claimed)

## Tools and services named
- Google Gemini ("Nano Banana") — AI image generation for banners, trust-badge icons, lifestyle photos
- Claude (with a pre-built brand-voice Project) — rewriting all theme copy in brand voice
- Canva — logo/favicon templates (from earlier lesson), used again for icon cropping prep
- Build My Pod theme — the base Shopify theme template with pre-built click-to-edit sections, sizing guide template, and trust-badge blocks

## Watch-outs
- Don't install extra Shopify apps chasing a "better converting" theme — the instructor's first store was loaded with apps, which slowed the site and hurt conversion; almost none of that effort moved sales. `[03:22:58]`
- Remember to click "Apply" after cropping an image in Shopify's editor, not just "Save" — Save alone won't apply the crop. `[03:31:26]`
- Large image file sizes can silently fail to upload (drag-and-drop just does nothing) — reduce file size if an upload doesn't take. `[03:36:20]`
- Gemini can drift and reuse unwanted elements from earlier prompts in the same chat (e.g., kept adding toilet paper to unrelated images) — start a new chat when output goes off-track. `[03:57:44]`
- Don't claim social proof you don't have yet (specific review counts, star ratings, customer counts) — replace with guarantees/claims you can actually back. `[03:48:20]`
- Keep CTA button color consistent site-wide — switching colors between sections removes the "trained" visual cue for customers to click. `[04:02:11]`
