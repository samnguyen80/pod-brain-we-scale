# 2.3 Scale to 100 Designs

Stage: 2) Design
Video: https://www.youtube.com/watch?v=hduC-C8pBpE&t=5744s
Transcript: [../../transcripts/2-3-scale-to-100-designs.md](../../transcripts/2-3-scale-to-100-designs.md)

## The job of this lesson
A merchant should walk away able to mass-produce roughly 100 print-ready designs in a few hours by combining two AI tools (WeScale Design Gem in Gemini + WeScale Design GPT) in a split-screen workflow, understand why 100 is the right target, and adopt a volume-over-perfection mindset for shipping designs daily.

## Playbook
1. Understand the math: historically 5-10% of designs become winners, so 100 designs yields ~5-10 potential winners — framed as the foundation for $10,000 in sales. A shop with only ~5 designs looks unfinished; 100 looks like a full, authentic brand and builds purchase confidence (cited reviews mention "lots of choices," "wide selection"). `[01:36:13]`
2. Set up a two-screen workflow: WeScale Design Gem (via gemini.google.com, direct gem URL shared in the free community) for prompt generation in one tab, split-screened next to the image generator via Chrome's "arrange split view." `[01:38:07]`
3. In the Gem, type just the niche + "designs" (e.g. "golf designs") — research is baked in, and it returns ready-to-use prompts built on proven niche slogans/motifs; copy each prompt into the image generator, which should be Nano Banana Pro (not the Gem itself — that's prompt-only and slower/lower quality for images). `[01:38:35]`
4. While one image renders, ask the Gem for more prompts or steer it toward research-backed cross-niche combos (e.g. "[niche] times [motif]," "[niche] times beer," gaming/8-bit crossovers) to keep the pipeline moving. `[01:41:17]`
5. Request style modifiers directly in-chat when a design is close but not right (e.g. "add a grunge effect to the design") instead of regenerating from scratch. `[01:43:58]`
6. Also generate in parallel inside the WeScale Design GPT (ChatGPT) — it produces a noticeably different visual style than Gemini, so running both tools adds variety; ChatGPT can remove backgrounds in-chat, Gemini cannot. `[01:47:56]`
7. Use saved research images as generation seeds: upload an Etsy inspiration screenshot and ask for "prompt variations of this image" to get several strategically varied concepts inspired by (not copying) the reference. `[01:50:54]`
8. Repeat the generate → review → light-edit loop across both tools until ~100 designs exist. `[01:50:22]`
9. Batch-prep every design in Canva exactly as done for the first 5: fill a 5000x5000 canvas, run background removal, manually restore any incorrectly erased areas, erase stray artifacts, and center/resize designs that don't fill the frame. Skip duplicate light/dark color variants during initial testing — build the second color only once a design is confirmed a winner. `[01:53:54]`
10. Before moving on, run the "100 design recap": generated, upscaled, background removed, named, saved to folder, ready to upload. `[02:05:13]`

## Tools and services named
- WeScale Design Gem (Gemini) — via gemini.google.com, custom Gem for niche-specific bulk design prompt generation `[01:38:07]`
- Nano Banana Pro — AI image generator used for image output from Gem prompts, preferred over base Nano Banana `[01:39:31]`
- WeScale Design GPT (ChatGPT) — alternate generation tool with a different visual style than Gemini; can remove backgrounds in-chat `[01:47:56]`
- Canva Pro — batch background removal and print-prep `[01:53:54]`
- Google Chrome split view — for running Gem and image generator side-by-side `[01:39:05]`

## Watch-outs
- Don't upload a research/inspiration image and generate something that looks remotely similar to the original — copyright/trademark risk; use it only as a directional seed for genuinely new variations. `[01:50:54]`
- Don't over-invest time perfecting each design before market feedback — the instructor's framing is "invest the time making perfect designs after we've gotten feedback from the market, not before"; volume first, refinement later. `[02:02:54]`
- Don't generate images inside the Design Gem itself — slower and lower-quality output than a dedicated image tool. `[01:39:59]`
- Watch for design elements that don't earn their place (e.g. an unnecessary added frame/border) — strip these out in Canva rather than keeping them. `[01:44:30]`
- Check every background-removed image carefully — small missed areas (partial letters, thin edges) are common and must be manually restored. `[01:58:44]`
- The "jar story" analogy: a class that made many jars produced the best jar, not the group that spent the semester on one — used to justify prioritizing volume over perfectionism.
